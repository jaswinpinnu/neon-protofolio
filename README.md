# NEON//AFTERDARK — Jaswin Pinnu Portfolio

A responsive cyberpunk portfolio built with HTML, CSS, vanilla JavaScript, Three.js, and GSAP.

## Run locally
1. Extract the ZIP.
2. Open a terminal in this folder.
3. Run `python -m http.server 8000`
4. Visit `http://localhost:8000`

You can also use VS Code Live Server. A local server is recommended because browser security rules may block scripts or assets when opening HTML directly.

## Included
- Procedural Three.js cyberpunk city, animated hero sculpture, stars, and rain
- Responsive navigation and layout
- Project case-study modals for the two resume projects
- Scroll reveals and optional GSAP / ScrollTrigger motion
- Skills, experience, education, certifications, contact details, LinkedIn, and GitHub
- Reduced-motion CSS support and mobile layout

## Resume download
Place your original resume PDF in this folder and name it `Jaswin_Pinnu_Resume.pdf` so the hero's Download Resume link works. The provided PDF is not duplicated inside this ZIP.

## Personalization notes
- Content was taken from the uploaded resume.
- Skill bar lengths are visual decoration, not claims of measured proficiency; change or remove them if you prefer.
- No live demo links were invented for the projects.
- Three.js, GSAP, and Google Fonts are loaded from CDNs, so the page needs an internet connection for those libraries/fonts.
